1. Domaine & ICANN

Achat d’un domaine personnalisé afin d’obtenir une adresse web professionnelle et masquer l’URL GitHub Pages.

  • Validation ICANN obligatoire
  • Gestion des extensions (.com, .xyz…)
  • Activation email propriétaire

2. Cloudflare & Reverse Proxy

Cloudflare agit comme CDN, WAF, Reverse Proxy et gestionnaire DNS.

  • Protection DDoS
  • HTTPS automatique
  • Masquage du serveur réel

3. DNS & Nameservers

Les DNS traduisent un domaine vers un serveur cible.

  • Cloudflare devient DNS autoritaire
  • Propagation DNS mondiale
  • Vérification via nslookup

4. GitHub Repository

Hébergement du site statique contenant les fichiers HTML/CSS/JS.

  • Versioning Git
  • Historique du projet
  • Déploiement automatisé

5. GitHub Pages

Transformation du repository en site web public.

  • Déploiement depuis la branche principale
  • Support HTML / CSS / JavaScript
  • Site statique uniquement

  • page1.html
  • page2.html
  • page3.html

Création d’un alias DNS reliant le domaine public au site hébergé.

  • Association domaine → hébergement
  • Configuration Cloudflare DNS

8. HTTPS & SSL/TLS

Chiffrement des communications entre le navigateur et le site.

  • Authentification
  • Intégrité des données
  • Certificats automatiques

9. WAF Cloudflare

Pare-feu applicatif protégeant le site contre scans, bots et attaques.
