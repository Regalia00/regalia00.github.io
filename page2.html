Build actif

Cette page présente les différents points techniques qui seront étudiés et réalisés dans le laboratoire. Le but principal est surtout de comprendre comment un site web moderne fonctionne réellement derrière son apparence visuelle.

Chaque partie du projet permet d’aborder une notion différente : réseau, sécurité, hébergement, DNS, reverse proxy et protection web.

Création du site web

Le site sert de base principale au laboratoire. Il permet de mettre en pratique les notions étudiées tout au long du projet.

  • Création des pages HTML
  • Organisation de la navigation
  • Compréhension du fonctionnement d’un site statique
HTML CSS GitHub Pages

Achat d’un nom de domaine

L’achat d’un domaine permet d’obtenir une adresse web plus professionnelle et plus simple à retenir qu’une adresse technique GitHub.

  • Comprendre le rôle des domaines Internet
  • Découvrir l’ICANN et la gestion DNS
  • Associer un domaine à un site web
DNS ICANN

Cloudflare & Protection Web

Cloudflare est utilisé pour comprendre comment un service peut protéger un site web tout en améliorant sa gestion réseau.

  • Protection HTTPS
  • Gestion DNS centralisée
  • Découverte du WAF et du filtrage
Cloudflare WAF

Proxy & Reverse Proxy

Cette partie du projet permet de comprendre comment le trafic réseau peut passer par un intermédiaire avant d’atteindre le serveur réel.

  • Comprendre le rôle d’un proxy
  • Découvrir le fonctionnement d’un reverse proxy
  • Observer la circulation du trafic web
Reverse Proxy Réseau

Compréhension des DNS

Les DNS sont une partie essentielle du projet car ils permettent de faire le lien entre un nom de domaine et le serveur qui héberge réellement le site.

  • Propagation DNS
  • Nameservers
  • Enregistrements CNAME
DNS Cloud

Finalité du projet

Le but final du laboratoire est surtout de mieux comprendre le fonctionnement global d’une infrastructure web moderne.

Ce projet permet de relier la théorie avec la pratique en observant concrètement comment les différents services communiquent entre eux sur Internet.

Ce que le projet permet de comprendre

01 / Réseau

Comprendre comment les requêtes circulent entre le navigateur et le serveur.

02 / DNS

Découvrir le rôle des domaines, des nameservers et de la propagation DNS.

03 / Protection

Observer comment Cloudflare protège un site grâce au reverse proxy et au WAF.

04 / Hébergement

Comprendre comment GitHub Pages publie un site statique sur Internet.
